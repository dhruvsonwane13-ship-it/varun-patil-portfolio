# Varun Patil — Data Analyst Portfolio

Responsive portfolio built with HTML, CSS, and vanilla JavaScript using the resume supplied for this project.

## Files
- `index.html` — page structure and resume-derived content
- `style.css` — responsive styling, illustrations, transitions, and layout
- `script.js` — mobile navigation, reveal-on-scroll animation, and dynamic year
- `assets/Varun_Patil_Resume.pdf` — downloadable resume

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Resume download works from the local `assets` folder.

No build tools or package installation are required. Google Fonts are loaded online; fallback fonts are provided.

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload the extracted files and folders, keeping `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the published URL shown in Pages settings.

## Notes
Project descriptions and training details come from the supplied resume. The resume did not include project repository URLs or certificate links, so these are not invented. Review contact details and resume content before publishing publicly.
